# CEO Challenge

## Descripción
CEO Challenge es un juego de simulación empresarial donde los jugadores asumen el rol de CEO y enfrentan diversos escenarios de gestión empresarial. El juego pone a prueba las habilidades de toma de decisiones estratégicas y muestra cómo estas afectan diferentes aspectos de la empresa.

## Características Principales
- Simulación de 20 escenarios empresariales desafiantes
- Sistema de impacto en tres áreas clave:
  - Finanzas
  - Reputación
  - Clima laboral
- Escenarios dinámicos y variados que incluyen:
  - Crisis de ciberseguridad
  - Expansión internacional
  - Gestión de recursos humanos
  - Transformación digital
  - Fusiones y adquisiciones
  - Crisis ambientales y de reputación

## Cómo Jugar
1. Inicia el desafío desde la página principal
2. Se te presentará el perfil de una empresa ficticia
3. Enfrenta diferentes escenarios empresariales
4. Analiza cada situación y elige entre cuatro opciones posibles
5. Observa cómo tus decisiones impactan en los diferentes aspectos de la empresa
6. Al final, recibe una evaluación de tus habilidades como CEO

## Tecnologías Utilizadas
- HTML5
- JavaScript
- Tailwind CSS para el diseño responsivo
- API de Gemini para la generación de escenarios dinámicos

## Instalación
1. Clona el repositorio
2. Abre el archivo `index.html` en tu navegador web
3. ¡Comienza a jugar!

## Estructura del Proyecto
- `index.html`: Interfaz principal del juego
- `scenarios.js`: Base de datos de escenarios predefinidos
